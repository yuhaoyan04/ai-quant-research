# 简历表述与项目说明

## 推荐项目名称

**A 股点时多因子选股与可成交风险归因系统** ｜ Python / pandas / scikit-learn / SciPy / Parquet

## 三条简历 bullet

- 搭建 2006–2026 A 股 PIT 横截面研究平台，覆盖 5,521 只历史股票和约 1,479 万行特征；实现历史股票池、下一交易日可用标签、purged walk-forward、15 因子 registry 与 50+ 个不可变实验版本。
- 将锁定HGB候选部署为forward-only paper-trading管线：冻结318,300条样本训练的模型包及SHA-256数据血缘，按真实交易日保存信号、约束目标、股数订单、模拟成交、现金、持仓与NAV，并以哈希链保留失败日和禁止历史回填；当前前瞻成功观测为0，不虚构paper业绩。
- 在统一样本上比较 Ridge、ElasticNet、RF 与 HGB，完成证监会宽行业+规模残差化及单股≤0.5%、行业主动权重±3%、|size-z|≤0.10、周换手≤30%的组合优化；20bp、停牌/涨跌停逐日重试后，HGB historical OOS 年化 20.81%、Sharpe 0.94、最大回撤 -33.32%。
- 构建人民币股数订单状态机与逐日现金/持仓/NAV 账本，覆盖 T+1、主板/科创板申报数量、10% 成交量参与率、部分成交、订单替换/过期和公司行动代理；全历史路径 0 个负现金日、0 个 T+1 违规，账户级受限年化 20.66%。
- 构建人民币国债rf、CSI价格/全收益双基准、PIT六风格模型与可成交Incremental Alpha Test；全收益基准使raw HGB CAPM Alpha由17.55%降至16.19%，六风格残余Alpha为-0.65%且不显著，同时识别局部选股与换手价值并拒绝“跨模型稳定纯Alpha”的过强结论。
- 设计validation-only残差收益challenger与严格行业/六风格复制基准，并在复核中识别33个重叠5日收益窗口、注销虚高绩效；重建1,210日唯一NAV账户后增量仅0.33%且区间跨零，再用OFAT/waterfall将residual的16.08个百分点实施缺口对账为交易状态8.22pp、条件性容量7.83pp、整手0.03pp、T+1 0.00pp，拒绝不达标的paper晋级。

## 30 秒版本

我做的不是单纯调模型，而是把 A 股横截面研究从数据时序一直推到可成交和归因。项目用历史 PIT 股票池、行业和规模暴露训练 Ridge/HGB，再用显式行业、规模、单股和换手约束构造组合，最后用股数订单模拟涨跌停与停牌。最关键的结论是：策略可成交收益为正，但在本地六风格归因后纯 Alpha 不显著，所以我把它定义为受控风格溢价，而不是夸大成选股神器。

## 使用原则

- 简历可写上述回测数字，但必须同时写 `historical OOS`，面试时主动说明不是实盘。
- 不写“年化 20.81% 的纯 Alpha”；正确表述是“可成交策略收益”，多因子残余 Alpha 不显著。
- 不宣称使用申万行业、官方历史 CSI 成分或券商冲击模型。
