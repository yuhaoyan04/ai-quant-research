# 全链路机构级再审计（2026-10-21）

## 审计结论

当前项目不是玩具回测：历史研究链已经覆盖 PIT 数据、因子与标签、时间感知训练、组合约束、股数级成交、现金/NAV 账本、中性化、风险归因、配对统计推断、不可变实验和前瞻 paper-trading 治理。本轮没有为了提高 2021–2026 收益修改信号、模型、组合或成本，也没有把已消费的 historical OOS 重新包装为独立测试集。

但“机构级”不能理解为已经等价于商业数据、券商 OMS 或实盘验证。本轮审计将实现正确性、研究证据和外部数据能力分开，修复了两个代码/治理缺口，并保留四类外部能力边界。

## 本轮修复

### P0 — 标签与滚动窗口的数据质量传播

旧实现的质量模块声明 `quality_status=fail` 不得用于研究，但标签函数没有显式屏蔽未来 fail 行；因子函数还会先删除 fail 行再滚动，可能压缩日期轴。V2 现在执行以下合同：

- rolling/shift 输入必须恰好包含一只证券，日期有效且唯一；
- fail 行保留在日期轴上，其研究字段置为缺失；
- 任一未来收益窗口包含 fail 行时，对应标签为缺失；
- 因子窗口不能跨过已知坏行后继续假装是连续 20/60/120 日窗口；
- 缺失关键 schema 字段在质量入口给出明确错误，而不是下游 `KeyError`。

全湖核对发现 5,524 个证券/指数文件中有 6 个 fail 行，其中 4 个属于 A 股，四者的 `pct_chg` 原本已经是缺失，因此冻结训练标签没有实际数值污染；另外两个带数值收益的 fail 行是 CSI 指数，不进入 A 股模型截面。这个修复是前瞻防护，不改变已发布收益结论。

### P0 — 冻结实验完整性门禁

旧工程门禁把“冻结实验必须正好等于某个硬编码数量”当作完整性条件。合法追加 Phase 11.1 后，53 个索引记录与 53 个冻结目录完全一一对应，门禁却错误失败。V2 改为检查：

- experiment ID 唯一；
- public index 与含 `FROZEN.json` 的目录双向一一对应；
- 每个索引项声明 immutable；
- 数量只设最低基线，不因合法追加实验而失败；
- 关键协议覆盖因子/中性化、成本、rf/基准、模型验证、OOS 治理、成交、组合、账本、统计、Alpha、paper 和 forward data 共 14 层。

## 研究结论是否改变

不改变。HGB/Ridge 的历史收益、增量 Alpha、风险归因和“纯选股 Alpha 未显著成立”的结论仍引用原冻结实验。数据合同 V2 与工程质量 V2 是治理/正确性升级，不是新的策略回测，也没有产生可用于选参的 2021–2026 新证据。

后续研究只能在新数据或明确声明为探索性的授权数据实验上推进；paper-trading 达到预设样本门槛前，`ready_for_live_capital` 必须保持 `False`。
