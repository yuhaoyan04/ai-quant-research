# Phase 9：风险基准与增量 Alpha 证据矩阵

Phase 9 不再把 CAPM 截距、六风格残差和可交易增量收益混成同一个“Alpha”。它在相同的 1,387 个交易日上建立五层证据：组合绝对收益、CSI500 CAPM Alpha、CSI500 加六风格 Alpha、ML 相对风格复制组合的原始配对差，以及该配对差的市场与六风格调整截距。

## 主规格与敏感性

主规格预先固定为：中债 3 个月国债收益率、CSI500 官方全收益指数、HAC(5) Bartlett 标准误。敏感性同时保存：

- 零利率、3 个月和 1 年中债国债收益率；
- 中证官方价格指数与全收益指数；
- HAC lags 5、10、20、40。

由此形成 `4 候选 × 3 rf × 2 指数口径 × 4 HAC = 96` 个风险调整增量回归。敏感性规格不用于重新选择模型或挑选最有利结果。

## 主要结果

|---|---:|---:|---:|---:|
| HGB industry+size neutral | 20.14% / 15.85% | 3.65% [0.03%, 7.17%] | 1.22% [-2.14%, 4.58%] | 未通过，q=59.71% |
| HGB raw | 20.66% / 17.50% | 2.81% [-0.85%, 6.33%] | 0.17% [-3.19%, 3.53%] | 未通过，q=59.71% |
| Ridge industry+size neutral | 15.78% / 13.35% | 2.06% [-1.65%, 5.83%] | -0.44% [-3.98%, 3.09%] | 未通过，q=59.71% |

CAPM Alpha 在部分候选上显著为正，但加入本地 PIT 规模、Beta、波动率、流动性、价值和动量后，组合截距全部跨零。进一步对 ML 减风格复制组合的零成本差值回归后，四条风险调整截距仍全部跨零。当前证据支持“历史上有正的组合收益和风格收益”，不支持“已识别稳定纯个股 Alpha”。

## 执行与暴露边界

ML 与风格复制组合共享同一权重级日度执行器、20bp 成本、停牌/涨跌停逐日重试和 30% 周换手目标。报告保留双方成本、换手、阻塞权重、目标偏离、现金和 pending order 差异。

P0 已关闭：4条ML与4条风格复制目标均已通过同一人民币股数订单执行器重放。八条路径保存订单、成交、持仓、现金与NAV，按股数成交率为75.62%–99.49%；0次T+1违规，最大NAV对账误差约 `2.38e-7` 元。Phase 9 v2 状态为 `COMPLETE_SHARE_LEVEL_FILL_COMPARISON`。这些成交仍是日线收盘近似，不冒充真实券商回报。

行业使用 PIT 证监会宽行业，六风格为本项目本地构建的 PIT 自融资代理。它们不是申万细分行业或商业风险模型。匹配误差按 293 个调仓日逐项保存，尤其波动率、流动性和动量仍存在非零残差，因此风格复制组合是可审计的研究基准，不是完美复制。
