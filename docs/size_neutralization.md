# PIT 规模中性化实验

## 1. 为什么必须做

多因子模型表现良好，并不代表它获得的是纯个股 alpha。动量、波动率、Amihud 和估值因子都
可能间接偏向小盘股。若不测量并控制规模暴露，就无法回答“收益来自选股，还是来自承担小盘
风险”。本实验固定 5 日 rank 标签、15 因子、Ridge $\lambda=1$、Top-200、周频交易与 20 bp
成本，只改变因子是否对 PIT 规模做残差化。

## 2. PIT 规模代理

BaoStock 日行情同时提供成交额 $A_{i,t}$ 和换手率 $u_{i,t}$。换手率从百分数换成小数后：

$$
\widehat{\mathrm{FloatCap}}_{i,t}=\frac{A_{i,t}}{u_{i,t}/100}.
$$

它不是交易所发布的精确自由流通市值，但只使用当日可见字段，是可审计的 PIT 代理。零成交、
零换手或无效值保持缺失，不伪造规模。2006–2026 实际周频可交易面板的最小覆盖率超过
99.99%，所有年度股票—日期键唯一。

行业分类没有同等级别的带生效日期历史，因此本阶段只做规模中性化。把当前行业标签回填历史
会产生前视偏差，明确禁止。

## 3. 每日残差化

对日期 $t$ 的规模代理取对数、1%/99% 截尾和 z-score，记为 $s_{i,t}$。对每个已经完成
缩尾、填补与标准化的因子列 $x^{(j)}$，只在同日横截面估计：

$$
x^{(j)}_{i,t}=a^{(j)}_t+b^{(j)}_t s_{i,t}+\varepsilon^{(j)}_{i,t}.
$$

中性化管线使用残差 $\varepsilon^{(j)}_{i,t}$ 并再次做同日 z-score。缺失指示列也同样处理，
避免“某因子缺失”继续成为规模代理。训练、验证和测试日期分别独立估计截面回归，不跨时间
共享均值、方差或系数。

由于最终 Ridge 分数是残差因子的线性组合，中性化分数与当日 log 规模的一阶相关理论上为零。
实测 OOS 平均相关绝对值为 $8.4\times10^{-18}$。

## 4. 结果

| 指标 | 原始管线 | 规模中性化 |
|---|---:|---:|
| OOS Mean RankIC | 0.0977 | 0.0944 |
| OOS ICIR | 4.53 | 4.32 |
| 20bp 后年化收益 | 21.22% | 16.30% |
| Sharpe | 0.80 | 0.69 |
| 最大回撤 | -36.96% | -32.46% |
| 平均换手 | 56.30% | 57.54% |
| score–log(size) 相关 | -0.069 | 0.000 |
| Top-200 平均规模百分位 | 34.37% | 46.45% |

中性化相对原始模型的 OOS RankIC 差为 -0.00336，13 周 block bootstrap 95% 区间
[-0.00701, +0.00025]；年化算术净收益差为 -4.85 pct，区间 [-8.76, -0.54] pct。

结论不是“原模型无效”，而是更细致的两部分：

1. 原模型确实有显著小盘倾向，小盘暴露贡献了约 4.9 个百分点的年化算术收益，不能把全部
   收益宣称为纯选股 alpha；
2. 严格消除线性规模暴露后，RankIC 仍为 0.0944、年化收益 16.3%、Sharpe 0.69，信号没有
   消失；同时最大回撤改善约 4.5 个百分点。

逐年看，中性化在 2022 年小幅亏损，但在 2024 与 2026 年收益和回撤优于原模型。这说明规模
约束是 alpha、风险与容量之间的权衡，而不是只以收益最大化决定的开关。

## 5. 边界与下一步

- 规模代理来自成交额/换手率，不等同于官方自由流通市值；应在获得可靠估值表后交叉验证。
- 当前只消除了线性 log-size 暴露，Top-N 非线性截断后仍可能保留少量规模偏斜。
- 本实验冻结时尚缺 PIT 行业分类；后续阶段已用历史证监会宽行业完成 raw、size-neutral、
  industry-neutral、industry+size-neutral 四组配对实验，并进一步加入组合层主动权重约束。
  证监会宽行业仍不能替代带生效日期的申万细分行业或完整多因子风险模型。
